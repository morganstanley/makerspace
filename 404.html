                                                                    Level 3

                                                                    • Microbit - Introduction
                                                                      • Microbit - Advanced Programming
                                                                    • Micro:bit - Introdução
                                                                      • Micro:bit - Programação avançada
                                                                    • Micro:bit - Introduction
                                                                      • Micro:bit - Programmation avancée
                                                                    • 1 ) Advanced Programming
                                                                      • Inputs and Outputs - Work with real-world inputs and outputs.
                                                                      • Loops - Use forever loops to repeat animations or actions.
                                                                      • Conditions (If-Else Logic) - Respond to button presses or sensor values with conditions.
                                                                      • More Advanced Projects
                                                                      • 1. Dice Simulator - Shake the micro:bit to roll a digital dice.
                                                                      • 2. Thermometer - Show icons for hot/cold depending on temperature.
                                                                      • 3. Step Counter - Use accelerometer to track motion and count steps.
                                                                      • 4. Gesture-Based Control - Detect gestures like tilt, shake, or face up/down.
                                                                      • Tips for Exploring
                                                                    • 1 ) Programação avançada
                                                                      • Entradas e saídas - Trabalhe com entradas e saídas do mundo real.
                                                                      • Loops - Use loops forever para repetir animações ou ações.
                                                                      • Condições (lógica if-else) - Responda a presses de botão ou valores de sensor com condições.
                                                                      • Projetos mais avançados
                                                                      • 1. Simulador de dado - Agite o micro:bit para rolar um dado digital.
                                                                      • 2. Termômetro - Mostre ícones para quente/frio dependendo da temperatura.
                                                                      • 3. Contador de passos - Use o acelerômetro para rastrear movimento e contar passos.
                                                                      • 4. Controle baseado em gestos - Detecte gestos como inclinar, sacudir ou virar para cima/baixo.
                                                                      • Dicas para explorar
                                                                    • 1 ) Programmation avancée
                                                                      • Entrées et sorties - Travaillez avec des entrées et sorties du monde réel.
                                                                      • Boucles - Utilisez des boucles infinies pour répéter des animations ou des actions.
                                                                      • Conditions (logique Si-Sinon) - Répondez aux pressions de boutons ou aux valeurs des capteurs avec des conditions.
                                                                      • Projets plus avancés
                                                                      • 1. Simulateur de dé - Secouez le micro:bit pour lancer un dé numérique.
                                                                      • 2. Thermomètre - Affichez des icônes pour le chaud/froid selon la température.
                                                                      • 3. Compteur de pas - Utilisez l’accéléromètre pour suivre le mouvement et compter les pas.
                                                                      • 4. Contrôle basé sur les gestes - Détectez des gestes comme l’inclinaison, le secouement ou le face vers le haut/bas.
                                                                      • Conseils pour explorer
