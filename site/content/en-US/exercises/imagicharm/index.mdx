# ImagiCharm Workshop Series

Welcome to the ImagiCharm workshop series!

## What you will use

<a href="https://shop.imagilabs.com/products/imagicharm-1"><img src="https://shop.imagilabs.com/cdn/shop/products/icharmrenders_04.052.png?v=1664384843" alt="The imagiCharm programmable colorful device" width="360" /></a>

The [imagiCharm](https://shop.imagilabs.com/products/imagicharm-1) is a programmable, colorful device from Imagilabs that makes learning Python tangible and fun, in the classroom or at home. Students program it with Python to light pixels, mix colors and build animations.

_Image: product render from the [Imagilabs shop](https://shop.imagilabs.com/products/imagicharm-1), © Imagilabs, linked from the official site and not redistributed in this repository._

---

## Choose your learning path

- [Level 1: Moving Pixels](/exercises/imagicharm/level-1/)
  - Light up individual pixels, learn color mixing, and try simple animations. Beginner friendly!
- [Level 2: Programming Concepts](/exercises/imagicharm/level-2/)
  - Practice variables, functions, user input, and create basic pixel animations. For those with some Python experience.
- [Level 3: Rainbow Glow & Patterns](/exercises/imagicharm/level-3/)
  - Create rainbow effects, advanced color gradients, and draw patterns using loops. For advanced learners.
