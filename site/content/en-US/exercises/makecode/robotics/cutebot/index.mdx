## Cutebot with MakeCode

This Cutebot curriculum is now maintained directly in this repository so it can be updated, adapted, and taught without depending on an external upstream project.

The course introduces students to robotics through the BBC micro:bit and the ELECFREAKS Cutebot Pro robot using Microsoft MakeCode blocks. Students move from beginner interactions on the LED screen to guided robot behaviors with sensors, movement, and decision-making.

## What you will use

![ELECFREAKS Cutebot Pro smart robot car with a micro:bit](./cutebot-pro.png)

_Image: ELECFREAKS, from [pxt-cutebot-pro](https://github.com/elecfreaks/pxt-cutebot-pro) (MIT License, © 2022 ELECFREAKS)._

- **Robot:** [ELECFREAKS Cutebot Pro](https://github.com/elecfreaks/pxt-cutebot-pro), a micro:bit smart robot car with motors, ultrasonic sonar, line-following sensors and RGB headlights
- **Brain:** [BBC micro:bit](https://microbit.org), with an LED screen, buttons and sensors
- **Software:** [Microsoft MakeCode for micro:bit](https://makecode.microbit.org), a free block-based editor that runs in the browser

### What students build

Each lesson follows the same pattern: a short story hook, a live demo, a challenge for pairs, and a worked solution in MakeCode. Students learn how to use blocks, loops, sensors, variables, and conditional logic while building confidence with physical robot control.

### Why this is in this repo

The original curriculum lives in [ghalichraibi/makecode-cutebot-curriculum](https://github.com/ghalichraibi/makecode-cutebot-curriculum), but this project keeps the course content alongside the rest of the Makerspace materials so the workshop can be versioned and maintained in one place. Source files (snippets, rendered block pictures in English and French, build tools) live in `code/Extra/cutebot/`. Lesson text is licensed [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/); see `code/Extra/cutebot/NOTICE.md`.

### Instructor notes

- Students need a micro:bit and a Cutebot Pro per pair.
- Use the MakeCode extensions for the Cutebot Pro.
- Project mode works well for class demos, while Show blocks helps explain how code maps to the robot.
- The learning approach remains beginner-friendly: blocks first, then explanation, then challenge, then reflection.

### Recommended use in this repository

Use this course as part of the robotics pathway and keep any customizations in the same repo as the other Makerspace lessons and site content.
