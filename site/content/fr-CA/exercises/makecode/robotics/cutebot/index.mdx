## Cutebot avec MakeCode

Ce programme Cutebot est maintenant maintenu directement dans ce dépôt afin de pouvoir être mis à jour, adapté et enseigné sans dépendre d’un projet externe.

Le cours initie les élèves à la robotique avec le BBC micro:bit et le robot Cutebot Pro d’ELECFREAKS, en utilisant les blocs de Microsoft MakeCode. Les élèves passent d’interactions simples avec l’écran LED à des comportements de robot guidés, avec capteurs, mouvement et prise de décision.

### Ce que les élèves construisent

Chaque leçon suit le même schéma : une courte accroche, une démo en direct, un défi en binôme et une solution commentée dans MakeCode. Les élèves apprennent à utiliser les blocs, les boucles, les capteurs, les variables et la logique conditionnelle tout en prenant confiance dans le contrôle d’un robot réel.

### Pourquoi ce contenu est dans ce dépôt

Le programme original se trouve dans [ghalichraibi/makecode-cutebot-curriculum](https://github.com/ghalichraibi/makecode-cutebot-curriculum), mais ce projet conserve le contenu du cours avec le reste du matériel Makerspace afin que l’atelier soit versionné et maintenu au même endroit. Les fichiers sources (extraits de code, images de blocs en anglais et en français, outils de génération) se trouvent dans `code/Extra/cutebot/`. Le texte des leçons est sous licence [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/deed.fr) ; voir `code/Extra/cutebot/NOTICE.md`.

### Notes pour l’enseignant

- Il faut un micro:bit et un Cutebot Pro par binôme.
- Utilisez les extensions MakeCode pour le Cutebot Pro.
- Le mode Projet convient bien aux démos en classe, tandis que l’affichage des blocs aide à expliquer le lien entre le code et le robot.
- L’approche reste adaptée aux débutants : les blocs d’abord, puis l’explication, puis le défi, puis la réflexion.

### Utilisation recommandée dans ce dépôt

Utilisez ce cours dans le parcours de robotique et gardez toute personnalisation dans le même dépôt que les autres leçons Makerspace et le contenu du site.
