# Micro:bit - Programmation de base

Bienvenue au niveau 2 ! Dans cette section, vous découvrirez les bases de la programmation avec le Micro:bit. Vous utiliserez un codage par blocs pour créer des projets interactifs, apprendrez à contrôler les LED, à réagir aux pressions de boutons et à utiliser les capteurs intégrés. Parfait pour les débutants prêts à faire le prochain pas dans la programmation !
