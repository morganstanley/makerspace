Vous pouvez utiliser Python pour faire des calculs avec les quatre opérations de base :

* `+`  Addition
* `-`  Soustraction
* `*`  Multiplication
* `/`  Division

Vous pouvez aussi utiliser des parenthèses pour contrôler l’ordre des opérations :

```python
(45/5 + 23) * 100
```
*Résultat :*
```python
3200.0
```
