Les variables servent à stocker des valeurs de données. Utilisez le signe égal pour assigner une valeur à une variable. Une fois qu’une variable a été créée, elle peut être utilisée dans des calculs. Vous pouvez afficher la valeur d’une variable en utilisant `print()`.

```python
coins = 10
coins = coins + 5
print(coins)
```
*Résultat :*
```python
15
```
