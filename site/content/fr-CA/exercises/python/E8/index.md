Les variables peuvent stocker des données de différents types — jusqu’à présent, nous avons discuté des nombres (entiers et flottants), des chaînes, des listes et des bools. Vous pouvez déterminer le type d’une variable en utilisant `type()` :

```python
type(45)
```
*Résultat :*
```python
int
```

Voici le type chaîne :
```python
type("Hello")
```
*Résultat :*
```python
str
```

Le type liste :
```python
type([2, 5, 7, 10])
```
*Résultat :*
```python
list
```

Le type booléen :
```python
type(True)
```
*Résultat :*
```python
bool
```
