Começando com MakeCode - MakeCode é um ambiente de programação visual baseado em blocos para micro:bit.

🔗 [Editor MakeCode](https://makecode.microbit.org/)
🔗 [Documentação para iniciantes do MakeCode](https://makecode.microbit.org/docs)

### Primeiro programa: "Olá, mundo!"

Role uma mensagem na tela de LEDs do micro:bit.

🔗 [Role seu nome – projeto](https://makecode.microbit.org/projects/scroll-your-name)

### Outros projetos para iniciantes

### 1. **Animação de coração piscando** - Faça um ícone de coração piscar para sempre.

🔗 [Coração piscando – projeto MakeCode](https://makecode.microbit.org/projects/flashing-heart)

### 2. **Crachá com nome** - Mostre seu nome ou apelido com o toque de um botão.

🔗 [Projeto Crachá com nome](https://makecode.microbit.org/projects/name-tag)

### 3. **Smiley Button** - Pressione um botão para mostrar um sorriso.

🔗 [Ícones de botão](https://makecode.microbit.org/projects/button-icons)

### 4. **Exibição de temperatura** - Use o sensor de temperatura embutido para mostrar a temperatura atual.

🔗 [Projeto Temperatura](https://makecode.microbit.org/projects/thermometer)

## Habilidades que você aprenderá

- Usar entradas (botões)
- Exibir saídas (LEDs)
- Loops e eventos
- Sensores básicos (temperatura)
