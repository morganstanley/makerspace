# Micro:bit - Programação básica

Bem-vindo ao Nível 2! Nesta seção, você explorará os fundamentos da programação com o Micro:bit. Você usará programação baseada em blocos para criar projetos interativos, aprenderá a controlar LEDs, responder a presses de botões e usar sensores integrados. Perfeito para iniciantes prontos para dar o próximo passo na programação!
