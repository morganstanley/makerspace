Variáveis são usadas para armazenar valores de dados. Use o sinal de igual para atribuir um valor a uma variável. Depois que uma variável for criada, ela pode ser usada em cálculos. Você pode exibir o valor de uma variável usando `print()`.

```python
coins = 10
coins = coins + 5
print(coins)
```
*Saída:*
```python
15
```

## Exercícios
